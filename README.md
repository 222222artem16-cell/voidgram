# Voidgram

Приватный мессенджер в стиле Telegram: свой сервер + Android-клиент.

```
voidgram/
  server/   Node.js (>=22.5) + SQLite + WebSocket
  android/  Kotlin + Jetpack Compose (открывать в Android Studio)
```

## Что умеет (v0.1)

- Регистрация и вход (username + пароль, scrypt, токены сессий)
- Личные чаты и группы, поиск людей по имени/username
- Сообщения в реальном времени (WebSocket), история с подгрузкой
- Ответы, редактирование, удаление (владелец группы может удалять чужие)
- Реакции-эмодзи, поиск по сообщениям чата (API)
- Фото и файлы до 50 МБ
- Статус «в сети / был(а)», «печатает…», счётчики непрочитанных, галочки прочтения в личных чатах
- Профиль (имя, о себе)

Не реализовано: каналы, боты, секретные чаты/E2E, звонки, push-уведомления в фоне, стикеры, аватарки в UI (сервер их поддерживает).

## Запуск сервера

```bash
cd server
npm install
npm start            # слушает :8080, данные в ./data
npm test             # интеграционные тесты
```

Переменные: `PORT`, `DATA_DIR`.

## Запуск приложения

1. Откройте папку `android/` в Android Studio (Koala или новее), дождитесь синхронизации Gradle.
2. Эмулятор: на экране входа адрес сервера по умолчанию `http://10.0.2.2:8080`.
   Реальный телефон: `http://<IP-компьютера>:8080` в одной Wi-Fi сети.
3. Зарегистрируйте два аккаунта (на двух устройствах/эмуляторах) и пишите друг другу.

## Важно перед публичным использованием

- Поставьте сервер за HTTPS (nginx/Caddy) и уберите `usesCleartextTraffic` из манифеста.
- Трафик не имеет сквозного шифрования: сообщения хранятся на сервере в открытом виде.
- Добавьте лимиты запросов и подтверждение регистрации (сейчас регистрация открыта для всех).
